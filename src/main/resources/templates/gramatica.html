Gramática de RoboScript

Gramática libre de contexto en BNF, conjuntos FIRST y FOLLOW, tabla de análisis LL(1) y análisis predictivo con pila.

✓ La gramática es LL(1): ninguna celda de la tabla tiene más de una producción, así que se puede analizar de izquierda a derecha viendo un solo token. Conflictos

Gramática en BNF

No terminales en minúscula · TERMINALES (tokens) en mayúscula · ε = cadena vacía · Símbolo inicial: programa

programa ::= declaracion posicion lista

Producciones numeradas

El número se usa en la tabla LL(1) y en la traza del análisis.

Conjuntos FIRST y FOLLOW

No terminalFIRSTFOLLOW
programa { ROBOT } { $ }

FIRST(A): tokens con los que puede empezar A. FOLLOW(A): tokens que pueden aparecer justo después de A ($ = fin de archivo).

Tabla de análisis LL(1)

Cada celda [no terminal, token] indica qué producción aplicar. Celda vacía = error sintáctico. Pase el cursor sobre un número para ver la producción.
